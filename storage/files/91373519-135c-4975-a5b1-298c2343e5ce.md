# Cliente visual de notificaciones SAT

Aplicación FastAPI que autentica automáticamente contra el servicio SAT y ofrece una interfaz web para crear y actualizar notificaciones de embarques.

## Ejecutar

1. Cree un entorno virtual: `python -m venv .venv`
2. Actívelo en PowerShell: `.\.venv\Scripts\Activate.ps1`
3. Instale dependencias: `pip install -r requirements.txt`
4. Copie `.env.example` como `.env` y ajuste las credenciales si es necesario. Puede cargarlas desde su entorno o configurar su gestor de secretos.
5. Inicie: `uvicorn app:app --reload`
6. Abra `http://127.0.0.1:8000`

## Seguridad y token

El navegador se comunica solamente con este backend. El backend obtiene el token mediante `POST /token` con Basic Auth, lo conserva en memoria, lo reutiliza y lo renueva dos minutos antes de expirar. Si SAT responde `401`, renueva el token y repite la petición una vez.

> FastAPI no carga archivos `.env` por sí mismo. Para desarrollo puede definir las variables en PowerShell antes de iniciar el servidor o utilizar un gestor de secretos/servicio de despliegue.
